# Область задач

- Назначение области — …
- Применимые ограничения по ведению памяти области — …

Роль, сессию редактора, точку продолжения и адрес основания веди в **одной**
строке для своей области. Конкретный остаток и следующий шаг при препятствии
хранятся в карточке точки продолжения. В общей
области подставь имя роли, действующую сессию, свою точку продолжения и адрес
единственной общей записи выдач.

```markdown
<!-- ai-kit:scope {"editor":{"role":"Координатор продукта","session":"product-chat"},"continuation":"P/T-001","resources":"docs/tasks/resources.json"} -->
```

В области функции подставь местные роль, сессию и задачу, а также номер и
сохранённый адрес общего поручения.

```markdown
<!-- ai-kit:scope {"editor":{"role":"Координатор поиска","session":"search-chat"},"continuation":"F-search/T-002","mandate":{"task":"P/T-001","basis":{"commit":"ПОЛНЫЙ_КОММИТ","path":"docs/tasks/open/T-001/task.json"}}} -->
```

Общую выдачу начинает её редактор с `{"editor":"Координатор продукта","grants":[]}`.
Для выдачи функции добавь, например, `{"resource":"write","holder":"F-search","work":"P/T-001","revision":1}`.
Границы отрезка берутся из поручения. Поля и условия описаны в [договоре](../formats.md#card-actions).

В карточке хранится поручение с допустимым отрезком записи.
Исполнитель пишет только в выданных пределах и в свой определённый файл результата.
Единственный редактор сохраняет карточку, ссылки на представленные факты и решение принимающего.
Для назначений, использующих общий ресурс, заранее установи его владельца и проверь отсутствие незавершённого удержания.
